# 염료 실험 절차 — 염료 고르기, 색역 확인, 목표색 정하기

두 메모(「R, G, B를 각각 하나만 흡수하는 염료 조합과 색역」, 「목표색 #53F3B6이 추출 안 되는 이유」)의 내용을
실험 순서와 소프트웨어 기능으로 옮긴 것입니다. 전체 흐름은 다음과 같습니다.

```
① 염료 후보 준비 → ② 카메라 보정(E, κ) → ③ 색역 분석·염료 선정 → ④ 목표색 검사 → ⑤ 색 매칭 운전 → ⑥ 데이터 기록
        └ 시뮬레이터 UI 에서 ③·④ 를 미리 해 볼 수 있음 (이상적 CMY 비교 포함)
```

## 핵심 개념 한 줄씩

| 용어 | 뜻 |
|---|---|
| A = E c | 흡광도 A(R,G,B) = 감쇠 행렬 E(3×3) × 농도 c(C,M,Y). E 의 행 = 카메라 채널, 열 = 염료 |
| 이상적 CMY | 시안은 R 만, 마젠타는 G 만, 옐로는 B 만 흡수 → E 가 대각행렬. 흰색보다 어두운 **모든** 색을 만들 수 있음 |
| 교차 흡수 | 실제 염료는 흡수띠가 넓어 이웃 채널도 먹음 → E 의 대각 밖 성분. 이것 때문에 일부 선명한 색이 색역 밖이 됨 |
| 색역 안/밖 | c = E⁻¹A 의 세 성분이 모두 ≥ 0 이면 안. 어느 하나라도 음수면 밖 (농도는 음수가 될 수 없음) |
| 최근접 색 | 색역 밖일 때 비음수 최소제곱(NNLS)으로 구한, 만들 수 있는 가장 가까운 색. 잔차 ΔE2000 으로 거리 표시 |
| κ(E) | 조건수. 작을수록 측정 오차가 농도 오차로 덜 증폭됨. 3 이하 권장. singular(역행렬 없음)는 특정 색이 아니라 모든 색에서 생김 |
| 보정 농도 범위 | Beer–Lambert 선형성이 확인된 농도 구간. 목표 농도가 이 밖이면 역산을 믿을 수 없음 |

## ① 염료 후보 준비

- 식용색소 시안(청색 1호 계열), 마젠타(적색 계열), 옐로(황색 4/5호 계열) 를 각각 **1.00 g/L 스톡**으로 만든다 (config 의 `TankSpec.conc_mg_L = 1000`).
- 후보가 여러 개면(예: 청색 1호 vs 청색 2호) 후보마다 스톡을 따로 만든다. 선정은 ③ 에서 보정 행렬로 한다.
- 염료를 고를 때 볼 것 (메모 1 §4): 흡수 피크가 카메라 R, G, B 채널 중심(약 610 / 540 / 460 nm)에 오고, 띠가 너무 좁지도 넓지도 않은 것. 띠가 좁으면 신호가 작고 선형성이 나빠지고, 넓으면 교차 흡수가 커진다.

## ② 카메라 보정 — E 와 κ(E) 를 얻는다

[CAMERA_CALIBRATION.md](CAMERA_CALIBRATION.md) 의 순서 그대로 (settings → roi → reference → sample → fit).
핵심만 다시 적으면:

```bash
python -m cmysim.camera_tools reference                       # 물만 있을 때 I0 (0.6~0.85 가 되게 노출 조정)
python -m cmysim.camera_tools sample --dye C --conc 5          # 염료마다 4~5 농도 (흡광도 1.0 아래에서)
python -m cmysim.camera_tools sample --dye C --conc 10
...
python -m cmysim.camera_tools fit                             # → calibration.json (E, I0, κ, 시료 목록)
python -m cmysim.gamut matrix --calib calibration.json         # E, κ(E), 교차 흡수 비율, 등급 출력 (체크리스트 1)
```

`fit` 의 시료 목록이 calibration.json 에 함께 저장되므로, 염료별 **보정 농도 상한**이 자동으로 기록된다. ④ 의 범위 검사가 이것을 쓴다.

## ③ 색역 분석과 염료 선정

```bash
python -m cmysim.gamut map --calib calibration.json --target "#53F3B6" --out gamut.png   # a*b*·a*L* 평면 색역 지도
python -m cmysim.gamut compare blue1.json blue2.json --ideal                             # 후보 세트 비교표
```

비교표의 열:

| 열 | 뜻 | 좋은 방향 |
|---|---|---|
| κ(E) | 조건수 | 작게 (< 2 좋음, < 3 보통) |
| 교차max | 주 채널 대비 가장 큰 교차 흡수 비율 | 작게 (< 15 % 좋음, < 30 % 보통) |
| a*b* 면적 | 도달 가능 색의 a*b* 볼록껍질 면적 | 크게 (색역이 넓음) |
| L* min | 가장 어둡게 만들 수 있는 밝기 | 작게 |
| 탐침색 잔차 | 대표 목표색 6개에 대한 최근접 잔차 ΔE | 0 에 가깝게 |

`--ideal` 을 붙이면 같은 주 흡수 계수를 가진 **이상적 CMY(대각 E)** 행이 추가되어, 실제 염료가 이상에서 얼마나 떨어져 있는지 보인다.
설명용 기본 행렬의 경우: κ 1.57 → 1.20, 교차 17 % → 0, a*b* 면적 10 157 → 14 536, #53F3B6 잔차 16.6 → 0.

**선정 규칙**: κ 가 작고 교차가 작은 세트. 두 세트가 비슷하면 a*b* 면적이 큰 쪽, 그리고 실제로 쓸 목표색들의 탐침 잔차가 작은 쪽.

## ④ 목표색 검사 (메모 2 체크리스트 2·3)

```bash
python -m cmysim.gamut check --calib calibration.json --target "#53F3B6"
```

출력 순서:

1. E, κ(E), 교차 흡수 — 기록용.
2. 흡광도 A 와 **c = E⁻¹A 의 부호**. 음수 염료가 있으면 "색역 밖" 과 이유(어느 염료의 교차 흡수가 어느 채널을 이미 더 먹는지).
3. 물보다 밝은 채널이 있으면 "염료는 빛을 빼기만 함" 으로 불가.
4. NNLS 최근접 c* 와 그 색, 잔차 ΔE2000.
5. c* 가 **보정 농도 상한**이나 **스톡 농도**를 넘는지.

브라우저 UI 에서는 목표색을 입력하는 순간 "색역(gamut) 분석" 카드에 같은 내용이 뜨고, 점구름(도달 가능 색) 위에 목표 × 와 최근접 ○ 가 그려진다.
색역 밖이면 "이 색을 목표로" 버튼으로 최근접 색을 목표로 삼는다. 실험은 **도달 가능한 목표에서만** 의미가 있다.

목표색 정하는 요령:
- 점구름 안쪽, 경계에서 떨어진 색을 고른다. 경계(어떤 염료가 0 에 붙음)에서는 역산이 흔들린다.
- 필요 농도가 보정 범위 안인지 본다. 범위를 넘으면 더 묽은 목표를 쓰거나 보정 농도를 넓힌다.
- 이상적 CMY 에서만 되는 색(예 #53F3B6)은 실제 염료로는 **구조적으로 불가**. 제어나 학습으로 해결되지 않는다. 필요하면 ⑦.

## ⑤ 색 매칭 운전

UI 에서 목표색 → 시작. 또는 Pi 에서 `ai_node_main --target`. 운전 중 MEASURE 단계의 ĉ 는 항상 색역 안(c ≥ 0)으로 나온다.
영상 노이즈로 음수가 나오면 NNLS 가 0 으로 자르므로, 경계 근처 목표에서는 ĉ 의 한 성분이 0 에 붙어 흔들릴 수 있다. 그런 목표는 피하거나 트림 허용 오차를 키운다.

## ⑥ 데이터 기록 (학습용)

- 보정 때: calibration.json (E, I0, κ, 시료). 염료 세트를 바꿀 때마다 새 파일.
- 운전 때: `experiment` 모듈의 DatasetRecorder 가 2 s 마다 (RGB, ĉ, 실제 투입 농도, 목표, ΔE) 를 기록.
- 학습 데이터는 **색역 안에서만** 모은다. 농도 격자(gamut hull 의 c_max 안)에서 무작위로 투입하고 RGB 를 찍는 것이 가장 효율적.
- 학습 대상: (a) RGB → 농도 역산의 비선형 보정, (b) 목표색 → 첫 투입량. 색역 밖의 색을 정답으로 넣지 않는다.

## ⑦ 색역을 넓히려면 (메모 1 §5)

- 염료를 4~6개로 늘린다 (초록·빨강·파랑 계열 추가). 인쇄의 CcMmYK, OGV 와 같은 원리.
- 염료가 채널(3)보다 많으면 같은 색을 만드는 조합이 여러 개가 되므로 "농도 총합 최소" 같은 기준을 두고 NNLS 로 푼다. `optics.nnls3` 는 열 수가 3 보다 커도 그대로 동작한다 (지지집합을 전부 시험).
- 현재 패널은 펌프 3대라 제어기는 3염료 기준이다. 4번째 염료를 쓰려면 펌프·밸브 한 라인(P-104/XV-104 자리)을 추가하고 PUMP_IDS·TankSpec 을 늘려야 한다. 이는 공침 단계에서 산 펌프 자리와 겹치므로 결정이 필요하다.

## 흔한 오해

- "프린터로 찍히는 색이니 염료로도 된다" → 아니다. 토너는 CMYK 4색 안료를 흰 종이 위 점으로 섞는 것이라 계산도 색역도 다르다. K 는 어둡게만 하므로 밝은 선명한 색에는 도움이 안 된다.
- "singular 라서 안 된다" → 아니다. singular 는 모든 색에서 똑같이 나타난다. 특정 색만 안 되면 색역 밖이다. κ(E) 로 확인.
- "농도를 더 넣으면 된다" → 밝기는 올라가지 않는다. 염료는 빛을 빼기만 한다.
