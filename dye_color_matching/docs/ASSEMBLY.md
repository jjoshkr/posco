# 하드웨어 조립 단계별 안내 — Pi 5 + MCC 보드 스택, 인터페이스 보드(KiCad), 납땜, 점검

펄스(접점) 모드 기준입니다. 펌프 3대는 MCC 152 DIO 의 펄스로, 솔레노이드 밸브 3개는 24 V MOSFET 로,
압력 트랜스미터는 MCC 118 로 읽습니다. XTR111 (4–20 mA) 보드는 이 단계에서 필요 없습니다.

```
Pi 5 (I/O 노드)                 인터페이스 보드                       현장
┌──────────────┐  DIO 3.3 V   ┌────────────────────┐
│ MCC 152 #1   │─────────────▶│ PC817 ×3 (펄스)     │──접점──▶ 펌프 P-101~103 External contact
│ MCC 152 #2   │─────────────▶│ PC817 ×3 (Pause)    │──접점──▶ 펌프 Pause (RUN_ENABLE)
│              │─────────────▶│ IRLZ44N ×3 + 다이오드│──24 V──▶ 솔레노이드 XV-101~103
│ MCC 118 CH4  │◀─────────────│ 250 Ω 션트 + 보호    │◀─4–20 mA─ 압력 트랜스미터 (24 V 루프)
│ MCC 134 CH0  │◀──────────────────────────────────── K 열전대 (선택)
└──────────────┘               └────────────────────┘        24 V DIN 전원 (2.5 A 이상)
```

## 1단계. Pi 5 에 MCC 보드 4장 쌓기 (30분)

### 준비물
- 스태킹 헤더(2×20, 암, 다리 긴 것) 4개 — MCC 보드에 보통 포함
- M2.5 스탠드오프 11 mm 또는 12 mm × 보드당 4개, 나사·너트
- Pi 5 전원: 5 V 5 A USB-C (공식 27 W). HAT 4장이 5 V 레일을 같이 쓰므로 낮은 전원은 금물
- 냉각: 스택을 올리면 공식 액티브 쿨러가 안 들어갈 수 있음 → 첫 보드 스탠드오프를 16 mm 로 높이거나 측면 팬

### 순서
1. **전원 끄고** 정전기 주의(금속 만지고 작업).
2. **주소 점퍼** 설정. 각 MCC 보드의 A0·A1·A2 점퍼로 0~7 주소를 정합니다. 코드 기본값은

   | 보드 | 주소 | 점퍼 (A0 A1 A2) | 위치 권장 |
   |---|---|---|---|
   | MCC 152 #1 (펌프 P-101/102 펄스, XV-101/102) | 0 | 없음 | 맨 아래 (Pi 바로 위) |
   | MCC 152 #2 (P-103 펄스, XV-103, RUN_ENABLE) | 1 | A0 | 2층 |
   | MCC 118 (압력 CH4) | 2 | A1 | 3층 |
   | MCC 134 (열전대) | 3 | A0 A1 | **맨 위** (열 영향 최소) |

   주소 0 보드만 Pi 가 부팅 때 EEPROM 을 읽습니다. 나머지는 아래 3번의 명령으로 등록합니다.
3. 보드를 Pi 40핀 헤더에 **똑바로** 꽂고(핀 1 = 보드 모서리 사각 패드), 스탠드오프로 고정. 한 층씩 올리며 헤더가 휘지 않게 두 손으로 누릅니다.
4. 소프트웨어:

   ```bash
   sudo apt update && sudo apt install -y git python3-pip python3-numpy
   git clone https://github.com/mccdaq/daqhats && cd daqhats && sudo ./install.sh
   sudo daqhats_read_eeproms          # 스택의 모든 보드 EEPROM 을 읽어 등록 (보드를 바꿀 때마다)
   daqhats_list_boards                # 4장이 주소와 함께 보여야 함
   pip install pyzmq
   python -m cmysim.io_node_main list
   ```

   `list` 에 4장이 안 보이면: 점퍼 중복, 헤더 덜 꽂힘, `daqhats_read_eeproms` 안 함 중 하나입니다.
5. 보드 없이 DIO 만 확인: `python -m cmysim.io_node_main bench dio 6 1` 로 MCC 152 #1 DIO6 에 3.3 V 가 나오는지 멀티미터로 봅니다 (DIO6 ↔ GND). `bench dio 6 0` 으로 0 V.

### MCC 보드 단자 상식
- MCC 152: DIO0~7 (3.3 V 로직, 출력 전류 작음 → 반드시 포토커플러/MOSFET 를 거침), AO0/AO1 (0–5 V), GND.
- MCC 118: CH0~7 단일종단 ±10 V, GND 기준. 4–20 mA 는 **GND 쪽에 둔 250 Ω 션트**로 1–5 V 로 바꿔 읽음.
- MCC 134: 열전대 4채널, 나사 단자. 열전대 극성(K: 노랑 +, 빨강 −) 주의.

## 2단계. 인터페이스 보드가 해야 할 일 (신호 목록)

| # | 신호 | Pi 쪽 | 회로 | 현장 쪽 | 수량 |
|---|---|---|---|---|---|
| 1 | 펌프 펄스 | MCC 152 #1 DIO6, DIO7 / #2 DIO0 | DIO → 470 Ω → PC817 LED. PC817 출력(C, E) 이 펌프 접점 역할 | 펌프 External contact 입력 (무전압 접점) | 3 |
| 2 | 운전 허가 (Pause) | MCC 152 #2 DIO5 | DIO → 2N7000 → PC817 LED ×3 (각 330 Ω, 5 V 에서) → 펌프 Pause 접점 | 펌프 Pause 입력 | 1 입력 → 3 출력 |
| 3 | 솔레노이드 밸브 | #1 DIO4, #1 DIO5, #2 DIO4 | DIO → 100 Ω → IRLZ44N 게이트 (10 kΩ 풀다운). 드레인 → 코일 −, 코일 + → +24 V, 1N4007 플라이백 (캐소드 +24 V) | HTV 04L2-C DC24V (12 W, 0.5 A) | 3 |
| 4 | 압력 트랜스미터 | MCC 118 CH4 | +24 V → 트랜스미터 + ; 트랜스미터 − → 250 Ω 0.1 % → GND. CH4 를 250 Ω 양단(위쪽) 에. 병렬 100 nF, 5.1 V 제너(보호) | 2선식 4–20 mA, 0–10 bar | 1 |
| 5 | 상태 LED | 각 출력 | DIO 와 병렬로 LED + 1 kΩ (디버그용) | — | 7 |
| 6 | 공통 접지 | Pi GND ↔ 24 V GND | **한 점**에서만 연결 (스타) | — | 1 |

왜 이렇게 하나:
- **펄스에 PC817**: 펌프 접점 입력은 펌프 내부 5 V 가 나오는 무전압 접점용입니다. Pi 와 펌프의 접지를 섞지 않으려면 광절연이 안전합니다.
- **밸브에 MOSFET**: 0.5 A × 24 V 는 ULN2003 같은 달링턴에는 벅찹니다(발열). 로직레벨 MOSFET IRLZ44N 은 3.3 V 게이트로도 0.5 A 를 거의 발열 없이 켭니다. 코일을 끌 때 생기는 역기전력은 플라이백 다이오드가 흡수합니다.
- **션트를 GND 쪽에**: MCC 118 은 GND 기준 단일종단 입력이라, 션트를 루프의 아래(GND 쪽)에 두어야 1–5 V 가 그대로 읽힙니다.
- **Pause 는 끊기면 멈추게**: 펌프 메뉴에서 Pause 접점을 "닫힘 = 운전" 으로 설정합니다. 선이 빠지거나 Pi 가 죽으면 펌프가 멈추는 쪽이 안전합니다. 코드의 `run_enable_active_high` 가 이와 맞습니다.

### 펌프 쪽 설정 (gamma/X)
- 운전 모드 **Contact** (접점), 메모리 기능 **끔** (펄스를 쌓아 두지 않게), 1 펄스 = 1 스트로크(배율 1:1), 스트로크 길이 100 %.
- 외부 제어 케이블(5선 범용 제어 케이블)의 핀 배정은 **펌프 매뉴얼의 표로 확인**하세요. gamma/X 계열은 보통 Pause 1쌍, External contact 1쌍, 공통 GND 가 한 케이블에 있습니다. PC817 출력 극성: 컬렉터를 펌프 쪽 + (내부 5 V), 이미터를 펌프 쪽 GND 에.
- 최소 펄스폭은 매뉴얼에 있고, 코드 기본 `pulse_ms = 20` 은 넉넉한 값입니다.

## 4단계. KiCad 로 회로 그리기 (처음이면 2~3시간)

### 설치와 프로젝트
1. kicad.org 에서 KiCad 9 설치 (Windows). 실행 → File → New Project → `io_interface`.
2. 프로젝트 창에서 **Schematic Editor** 열기.

### 회로도(Schematic) 그리기
3. **심볼 배치** (단축키 `A`, 검색어):
   - `PC817` → Isolator 라이브러리 PC817 ×6
   - `IRLZ44N` → Transistor_FET ×3, `2N7000` ×1
   - `R` ×24, `C` ×2, `D` → 1N4007 ×3, `D_Zener` ×1, `LED` ×7
   - `Screw_Terminal_01x02` / `01x03` → Connector 라이브러리 (단자대)
   - `+24V`, `+5V`, `+3V3`, `GND` 전원 심볼 (`P`)
4. **배선** (`W`). 선을 다 끌기보다 **네트 라벨**(`L`)을 씁니다. 같은 이름이면 연결됩니다. 아래 네트 표대로 라벨을 붙이면 됩니다.

   | 네트 이름 | 연결되는 핀 |
   |---|---|
   | DIO_P101 | 단자대 J_DIO 핀 1 — R470 — PC817_1 애노드(1) |
   | DIO_P102 | J_DIO 핀 2 — R470 — PC817_2 애노드 |
   | DIO_P103 | J_DIO 핀 3 — R470 — PC817_3 애노드 |
   | PC817_n 캐소드(2) | GND_PI |
   | P101_C+, P101_C− | PC817_1 컬렉터(4), 이미터(3) → 단자대 J_P101 |
   | DIO_RUN | J_DIO 핀 4 — R10k 풀다운 — 2N7000 게이트 |
   | 2N7000 드레인 | PC817_4,5,6 캐소드 (각 LED 애노드는 R330 거쳐 +5V) ; 소스 = GND_PI |
   | PAUSE_n+/− | PC817_4,5,6 컬렉터/이미터 → J_PAUSE_101/102/103 |
   | DIO_XV101/102/103 | J_DIO 핀 5~7 — R100 — IRLZ44N 게이트 ; 게이트–GND 에 R10k |
   | XV101_COIL− | IRLZ44N 드레인 ; 1N4007 애노드 |
   | +24V | 코일 + ; 1N4007 캐소드 ; 퓨즈 거쳐 J_24V 핀 1 ; 트랜스미터 + |
   | GND_24 | IRLZ44N 소스 ; J_24V 핀 2 ; 션트 아래쪽 |
   | PT_LOOP | 트랜스미터 − → R250 위쪽 ; 100 nF ; 제너 캐소드 ; J_AI 핀 1 (→ MCC 118 CH4) |
   | GND_PI ↔ GND_24 | **한 곳**에서 `Net tie` 심볼 또는 0 Ω 저항으로 연결 |

   +5V 는 MCC 152 단자가 아니라 Pi 40핀 헤더의 5 V 핀(또는 별도 5 V)에서 가져옵니다. 3.3 V 가 아닌 5 V 를 쓰는 이유는 PC817 LED 3개를 한 트랜지스터로 켤 때 여유가 필요해서입니다.
5. **Annotate** (Tools → Annotate Schematic) 로 R1, R2… 번호 부여.
6. **ERC** (Inspect → Electrical Rules Checker). 전원 핀 "not driven" 경고는 전원 심볼에 `PWR_FLAG` 를 붙이면 사라집니다.
7. **풋프린트 지정** (Tools → Assign Footprints):
   - PC817 → `Package_DIP:DIP-4_W7.62mm`
   - IRLZ44N → `Package_TO_SOT_THT:TO-220-3_Vertical`
   - 2N7000 → `Package_TO_SOT_THT:TO-92_Inline`
   - 저항 → `Resistor_THT:R_Axial_DIN0207_L6.3mm_D2.5mm_P10.16mm_Horizontal`
   - 1N4007·제너 → `Diode_THT:D_DO-41_SOD81_P10.16mm_Horizontal`
   - 100 nF → `Capacitor_THT:C_Disc_D5.0mm_W2.5mm_P5.00mm`
   - LED → `LED_THT:LED_D3.0mm`
   - 단자대 → `TerminalBlock_Phoenix:TerminalBlock_Phoenix_MKDS-1,5-2_1x02_P5.00mm` (3P 는 `_1x03_`)

### 기판(PCB) 배치
8. PCB Editor 열고 Tools → **Update PCB from Schematic** (F8). 부품이 뭉쳐서 나옵니다.
9. **외곽선**: Edge.Cuts 레이어에 사각형 80×90 mm. 네 모서리 M3 구멍(`MountingHole_3.2mm`).
10. **배치 원칙**: 왼쪽 = Pi 쪽(3.3 V/5 V, DIO 단자대, PC817 입력), 오른쪽 = 현장 쪽(24 V, 펌프 접점, 밸브, 트랜스미터). PC817 이 경계가 되게 가운데 세로로 줄 세움. 24 V 부품과 Pi 쪽 부품 사이 **3 mm 이상** 비움.
11. **트랙 폭**: 신호 0.3 mm, 24 V·코일 1.0 mm, GND 는 양면 **구리 영역(Zone)** 으로. GND_PI 와 GND_24 영역을 따로 두고 한 점(0 Ω)에서만 연결.
12. 라우팅 (`X`), 안 되는 건 비아(`V`)로 뒷면. 자동 라우터는 쓰지 않아도 이 규모(부품 50개)는 1시간이면 끝납니다.
13. **DRC** (Inspect → Design Rules Checker) 0 에러.
14. 출력: File → **Plot** → Gerber (F.Cu, B.Cu, F.SilkS, F.Mask, B.Mask, Edge.Cuts) + Generate Drill Files. ZIP 으로 묶어 JLCPCB/PCBWay 에 업로드 (2층, 1.6 mm, HASL, 5장 약 $5 + 배송, 1~2주).

### 먼저 만능기판으로
PCB 를 기다리는 동안 같은 회로를 **만능기판**에 만들어 쓰면 됩니다. 회로도의 네트 표가 곧 배선표입니다. 펄스 3채널 + 밸브 3채널이면 70×90 mm 기판 한 장에 들어갑니다.

## 5단계. 납땜 (처음이면 2시간)

- 인두 350 °C, 유연 납 0.8 mm(초보는 유연이 쉬움), 플럭스 펜, 니퍼, 핀셋, 흡입기.
- **낮은 부품부터**: 저항 → 다이오드(띠 방향!) → DIP 소켓(홈 방향) → 세라믹 캡 → LED(긴 다리 +) → 2N7000 → 단자대 → IRLZ44N(마지막, 방열판 있으면 함께).
- 한 땀: 패드와 다리에 인두를 2초 대고 납을 대면 흘러들어감 → 인두를 뗌. 1~2초 안에 끝나야 함. 둥글게 솟은 산 모양이 정상, 공 모양·광택 없음은 다시.
- 다 하고 **멀티미터 저항 모드**로: +24V–GND_24, +5V–GND_PI, +3V3–GND_PI 가 단락(0 Ω)이 아닌지. 플라이백 다이오드가 거꾸로면 +24V–XVn_COIL− 가 다이오드 순방향(0.6 V)으로 나오므로 다이오드 모드로 확인.
- PC817 과 MOSFET 는 소켓/마지막에 꽂아 열 손상 방지.

## 6단계. 단계별 전원 투입과 점검

1. **24 V 없이**, Pi 만 켜고 인터페이스 보드의 DIO 단자대만 연결.

   ```bash
   python -m cmysim.io_node_main bench dio 6 1      # P-101 상태 LED 켜짐, PC817_1 출력 저항 수십 Ω (다이오드 모드)
   python -m cmysim.io_node_main bench blink 6      # 깜빡임 → 펄스 경로 OK
   ```

   밸브 채널은 게이트에 3.3 V 가 걸리는지 멀티미터로.
2. **24 V 투입**, 밸브 한 개만 연결. `bench dio 4 1` → 밸브가 "딸깍", 코일 전류 약 0.5 A. 끌 때 플라이백이 없으면 스파크/리셋이 나므로 여기서 확인.
3. **펌프 1대**: Contact 모드로 두고 External contact 에 PC817_1 출력 연결, Pause 에 PC817_4 출력 연결. `bench dio 5 1`(RUN_ENABLE, #2 보드) 후 `bench blink 6` → 펌프가 스트로크를 한 번씩 침. 저울 위 비커로 100 펄스 → mL 재서 `stroke_mL` 실측값 기록.
4. **압력**: 트랜스미터 연결, 라인에 압력 없을 때 CH4 ≈ 1.0 V (4 mA). `python -m cmysim.io_node_main run --pump-mode pulse -v` 의 텔레메트리에 pressure_bar ≈ 0.
5. 전체: `run --pump-mode pulse -v` + AI 노드 `ai_node_main --target ...`. 첫 운전은 물만 넣고 `--mode open` 으로 투입 부피를 확인한 뒤 `closed`.

**전원 순서**: 켤 때 Pi → 24 V, 끌 때 24 V → Pi. 비상시에는 24 V 를 먼저 끊으면 밸브가 닫히고(NC) 펌프는 Pause 가 열려 멈춥니다.

## 안전 체크리스트
- 24 V 와 Pi 3.3 V 쪽은 보드 위에서 공간을 띄우고 접지는 한 점에서만.
- 모든 코일에 플라이백 다이오드. 없으면 MCC 보드가 리셋되거나 망가집니다.
- 펌프 Pause 는 "닫힘 = 운전" 으로 설정해 선이 빠지면 멈추게.
- 24 V 라인에 퓨즈 2 A.
- 배관 쪽은 밸브 닫힌 채 펌프가 돌지 않도록 코드 인터록이 막지만, 처음 시험은 배압 밸브 설정(2 bar)과 릴리프 경로를 확인한 뒤에.
