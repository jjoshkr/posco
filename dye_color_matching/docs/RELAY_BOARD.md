# 릴레이 제어보드로 할 때 — MCC 와의 관계, 연결, 극성, 납땜 점검

**관계**: 릴레이 보드는 MCC 152 의 DIO(3.3 V, 전류 몇 mA)와 현장(펌프 접점, 24 V 솔레노이드) 사이에 들어가는 "힘 증폭기"입니다.
[ASSEMBLY.md](ASSEMBLY.md) 의 인터페이스 보드(PC817 + IRLZ44N)와 **같은 자리, 같은 역할**이고, 부품만 릴레이로 바뀝니다.
MCC 없이는 릴레이를 켤 신호가 없고, 릴레이 없이는 MCC 가 펌프·밸브를 직접 움직일 수 없습니다.

```
MCC 152 DIO (3.3 V 신호)  →  릴레이 보드 IN  →  릴레이 코일 (5 V)  →  접점 COM/NO  →  펌프 접점 입력 / 24 V 솔레노이드 코일
```

## 1. 채널 배정 (인터페이스 보드와 동일)

| 릴레이 CH | MCC 152 단자 | 접점이 하는 일 | 접점 배선 |
|---|---|---|---|
| 1 | #1 DIO6 | P-101 펄스 (External contact) | COM → 펌프 GND(검정), NO → External contact(흰색) |
| 2 | #1 DIO7 | P-102 펄스 | 〃 |
| 3 | #2 DIO0 | P-103 펄스 | 〃 |
| 4 | #2 DIO5 | RUN_ENABLE → 펌프 3대 Pause | 펌프마다 릴레이 1개가 깔끔(4·5·6). 1개로 하려면 3대 Pause 를 병렬로 — 펌프 GND 가 서로 묶이므로 권장하지 않음 |
| 5, 6 | (#2 DIO5 공통) | P-102, P-103 Pause | COM → 펌프 GND, NO → Pause(갈색) |
| 7 | #1 DIO4 | XV-101 | COM → +24 V, NO → 코일 1, 코일 2 → 24 V GND, **코일 양단에 1N4007** |
| 8 | #1 DIO5 | XV-102 | 〃 |
| 9 (2번째 보드) | #2 DIO4 | XV-103 | 〃 |

8채널 보드 1장이면 Pause 를 릴레이 1개(4)로 쓰고 펌프 GND 를 공통으로 묶거나, 보드를 2장(8+4) 씁니다. 펌프 접점은 "무전압 접점"이라 **릴레이 접점이 바로 그 역할**을 하므로 가장 자연스럽습니다.

전원: 릴레이 보드 VCC 5 V ← Pi 40핀 핀 2, GND ← 핀 6. 8채널 모두 켜지면 약 0.6 A 를 먹으므로 Pi 전원이 27 W 인지 확인.
(JD-VCC 점퍼가 있는 보드는 점퍼를 빼고 JD-VCC 에 별도 5 V 를 주면 Pi 와 릴레이 코일 전원이 분리되어 더 안전합니다.)

## 2. 극성 — 가장 중요한 확인

시중 릴레이 모듈의 입력은 **로우 트리거(IN 이 LOW 일 때 릴레이 ON)** 가 많습니다. 그대로 쓰면 Pi 부팅 직후 DIO 가 입력(풀업)이라 **모든 릴레이가 켜져 펌프가 돌고 밸브가 열립니다.**

- 보드에 **High/Low 트리거 선택 점퍼**가 있으면 **High** 로 둡니다. 그러면 코드 기본값(`*_active_high = true`) 그대로.
- 점퍼가 없는 로우 트리거 보드면 `io_node.json` 에서 세 값을 `false` 로:

```json
"valve_active_high": false,
"run_enable_active_high": false,
"pulse_active_high": false
```

  코드는 부팅 때 펄스·밸브·운전허가 핀을 "꺼짐" 레벨(High)로 먼저 쓴 뒤 출력으로 바꾸고, 펄스는 Low 로 떨어졌다가 돌아옵니다 (`test_daqhats_low_trigger_relay_polarity`).
  그래도 Pi 가 꺼져 있을 때(DIO 플로팅)는 릴레이가 켜질 수 있으니, **High 트리거 보드가 안전합니다.**
- 확인 방법: 24 V 와 펌프를 연결하지 않은 채 Pi 를 재부팅하고, 부팅 내내 릴레이 LED 가 꺼져 있어야 합니다. `bench dio 6 1` 로 켜지고 `bench dio 6 0` 으로 꺼지면 극성이 맞습니다.

## 3. 펄스에 기계식 릴레이를 써도 되나

- 200 spm = 초당 3.3 회, 접점 닫힘 20 ms. 기계식 릴레이(응답 5~10 ms)는 동작은 하지만, 1시간에 12,000 회 → 전기 수명 10만~100만 회면 **10~80 시간**에 끝납니다.
- 그래서 **펄스 3채널은 PC817(또는 SSR)** 이 맞고, 릴레이는 **밸브·Pause 같은 느린 신호**에 쓰는 것이 좋습니다. 처음 며칠 시험은 릴레이로 해도 됩니다.
- 릴레이로 펄스를 칠 때는 `pulse_ms` 를 30 으로 올리고(`io_node.json`), `max_spm` 을 120 으로 낮추면 접점이 확실히 닫힙니다.

## 4. 솔레노이드를 릴레이로 켤 때

- 릴레이 접점은 24 V 0.5 A 에 충분(보통 10 A 정격). 단 **코일 양단 플라이백 다이오드(1N4007, 띠가 +24 V 쪽)** 는 그래도 달아야 합니다. 없으면 끌 때 수백 V 스파이크로 접점이 타고 Pi 가 리셋됩니다.
- 24 V GND 와 Pi GND 는 릴레이로 절연되므로 **접지 결합이 필요 없습니다**(인터페이스 보드 설계와 다른 점). PT 션트를 쓸 때만 MCC 118 GND 와 24 V GND 를 한 점에서 묶습니다.

## 5. 압력 트랜스미터는 릴레이 보드로 안 됨

4–20 mA → 1–5 V 변환은 저항 하나(250 Ω 0.1 %)입니다. 릴레이 보드와 무관하게 MCC 118 CH4–GND 사이에 션트를 달고, 트랜스미터 − 선을 CH4 에, +24 V 를 트랜스미터 + 에 연결합니다 ([WIRING.md](WIRING.md) W11·W12·W31·W32).

## 6. 납땜할 때 (키트형 릴레이 보드)

| 부품 | 확인 |
|---|---|
| 릴레이 | 핀 배열 방향(표시 선), 코일 전압 5 V 인지 |
| 구동 트랜지스터 / ULN2803 | 1번 핀·홈 방향. 거꾸로 끼우면 전 채널 상시 ON |
| 코일 플라이백 다이오드 (보드 위 1N4148/4007) | 띠(캐소드)가 +VCC 쪽 |
| 포토커플러(있으면) | 1번 점 방향 |
| 전해 콘덴서 | 긴 다리 +, 띠 − |
| 입력 저항 | 3.3 V 로 켜지는지: 트랜지스터형은 1 kΩ 정도면 OK, 포토커플러형은 IN–VCC 사이 LED 라 **로우 트리거** |
| 단자대 | 나사 방향이 바깥 |

납땜 후: 전원 없이 VCC–GND 저항(단락 아님), 각 IN–GND 저항(수 kΩ). 5 V 만 넣고 IN 을 GND(또는 3.3 V)에 대 보며 릴레이 "딸깍"과 LED. 그다음 MCC 에 연결해 `bench dio`.

## 7. 정리

- 릴레이 보드 = 인터페이스 보드의 릴레이 버전. MCC 152 DIO 가 입력, 접점이 출력.
- 밸브·Pause 는 릴레이로 좋고, 펄스 3채널은 수명 때문에 PC817 권장(처음엔 릴레이도 가능).
- 트리거 극성(High 권장)과 플라이백 다이오드가 안전의 핵심.
