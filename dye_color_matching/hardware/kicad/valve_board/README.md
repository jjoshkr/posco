# valve_board — 24 V 솔레노이드 4채널 연결 보드

채널마다 두 구동 방식 중 하나를 실장합니다.
- **방식 A (릴레이 스택)**: J(n) ← 32CH 릴레이 보드 출력 J(n) 의 L(스위치된 +24 V)·N(GND). JP(n) 1-2, JP(n+4) 1-2. Q·R1~8·R20·J9 비움.
- **방식 B (MCC 152 DIO 직접)**: J9 ← DIO1~4 + GND_PI. R(n) 100 Ω → Q(n) IRLZ44N, R(n+4) 10 kΩ 풀다운. JP(n) 2-3, JP(n+4) 2-3. R20 0 Ω 실장(접지 결합).
공통: D(n) 1N4007 플라이백(코일 양단), R(n+8) 4.7 kΩ + LED, J(n+4) 코일 단자(극성 무관). J10 24 V 입력(F1 2 A, D9 TVS, C1 100 µF). J11 → 릴레이 보드 J34 (L=+24V, N=GND, FG 통과). J12 → PT 루프 전원.
