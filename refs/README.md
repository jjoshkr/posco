# 레퍼런스 업로드 폴더

포스코 PR 영상 캡처나 영상 파일을 이 폴더에 올려 주세요.

- 캡처 이미지: PNG 또는 JPG, 영상별로 10~20장
- 파일 이름 예시: `posco_kr_0m35s.png` (영상 구분 + 시점)
- 영상 파일(mp4)도 가능합니다. GitHub 웹 업로드는 파일당 25MB까지입니다.

GitHub 웹에서 올리는 방법: 이 폴더 화면에서 Add file → Upload files → 파일을 끌어다 놓기 → 브랜치 `claude/youthful-wozniak-16iq7d`에 Commit changes.
