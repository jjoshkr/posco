# 포스코 스튜디오 영상 스타일 가이드 (레퍼런스 분석)

분석한 영상
- 「Panorama Walk」 티저 (42.7초, 광양 구봉산 전망대)
- 「STEEL DEFINES NEW ERA」 PR 필름 (3분 58초)

## 카메라
- 30~45도로 비스듬히 내려다보는 드론 항공샷과 광각 원근이 기본이다. 수평선은 화면 위쪽 15~25%에 둔다.
- 수직 탑뷰(바로 위에서 내려다보기), 천천히 밀고 들어가는 푸시인, 설비 사이를 낮게 통과하는 FPV 비행을 섞는다.
- 쇳물, 선재, 용접 같은 소재는 얕은 심도의 매크로 컷으로 잡는다. 컷 길이는 1~3초다.

## 색과 빛
- 청록-주황 색보정을 쓴다. 그림자와 바다는 짙은 청록, 하이라이트와 쇳물은 따뜻한 주황이다.
- 대비가 강하고 검정이 깊다. 원경에는 푸른 대기 안개를 깐다.
- 낮 장면은 짙은 파란 하늘과 바다, 해 질 녘 장면은 남색 하늘과 주황 수평선, 공장 나트륨 조명을 쓴다.

## 미래 설비 표현 (HyREX 장면)
- 실제 공장 위에 빛나는 청색 홀로그램 와이어프레임을 겹치고 빛 번짐(블룸)을 준다.
- 원형 링 안에 흰 「H₂」를 넣은 아이콘을 설비 위에 띄운다.

## 과학 설명 장면
- 따뜻한 베이지 무지 배경에 부드러운 스튜디오 조명을 쓴다.
- 3D 오브제(철광석, 분자 구)를 띄우고, 가는 선과 작은 글씨로 라벨을 단다.

## 글자
- 흰 고딕, 패널 없음, 약한 그림자만 쓴다.
- 장소·설비 이름은 오른쪽 아래에 「| 이름 |」으로 쓰고, 그 아래 작은 설명 한 줄을 붙인다.
- 감성 문구는 피사체 좌우로 나눠 배치한다(예: 「새로운 길이 | 열립니다」).
- 영문 키워드는 자간을 넓게 띄운다(예: 「P A N O R A M A」).
- 마지막은 검은 화면 가운데 흰 글씨, 그다음 흰 화면 카드로 끝낸다.
