# 글꼴

모든 장면은 Pretendard 1.3.9 가변 글꼴(굵기 45~930)을 씁니다. 인터넷 없이 열리도록 각 HTML 안에 글꼴을 넣었습니다.

- `PretendardVariable-subset.woff2`: 상용 한글 2,350자와 영문, 숫자, 장면에 쓰는 기호만 담은 서브셋입니다. 크기는 약 455KB입니다.
- `Pretendard-OFL.txt`: SIL Open Font License 1.1 원문입니다. 문서에 넣어 배포해도 되는 라이선스입니다.
